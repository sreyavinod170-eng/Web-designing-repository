PERSONAL PORTFOLIO WEBSITE - CLASSROOM DEMO

PROJECT FILES
- index.html: Home page
- about.html: About and education page
- projects.html: Skills and projects page
- contact.html: Contact form and social links
- style.css: Shared website styling

HOW TO RUN
1. Extract the MyPortfolio folder.
2. Open the folder in Visual Studio Code (optional).
3. Open index.html in a web browser.
4. Use the navigation links to visit the other pages.

CUSTOMISE BEFORE SUBMISSION
- Replace the sample name and initials.
- Add your own education and interests.
- Add your own skills and project descriptions.
- Replace the sample social media links with your profile URLs.
- Change the colours and layout to make the design your own.

NOTE
The contact form is only a front-end demonstration. The mailto action opens
the visitor's email application and does not save messages to a website
database. A backend or form service is needed for a fully working online form.
